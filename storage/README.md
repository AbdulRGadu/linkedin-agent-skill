# Local content state
ideas/ is for draft ideas, plans/ for weekly plans, logs/ for approved action history.
Original skill path mapping: ~/.claude/linkedin/plan.md → storage/plans/plan.md; ~/.claude/linkedin/log.md → storage/logs/log.md.
Hosts create these manually as needed; the MCP server does not write or persist them.
Directory contents are ignored except .gitkeep. Do not store credentials, confidential customers, or private message exports here. Production token storage must be secure and durable.
